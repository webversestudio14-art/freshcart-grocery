# 🛒 FreshCart - Grocery E-commerce Website

A modern, responsive grocery e-commerce website built for online grocery shopping.

## 🚀 Features

- User Registration & Login
- Grocery Categories
- Product Listing & Product Details
- Search & Category Filtering
- Shopping Cart
- Update Cart Quantity
- Cash on Delivery Checkout
- Order Placement
- User Profile
- Order History
- Admin Dashboard
- Product Management
- Category Management
- Order Management
- Responsive Design for Mobile, Tablet & Desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- React.js
- TypeScript
- Vite

⚙️ Installation & Setup
1. Clone the repository
git clone https://github.com/webversestudio14-art/freshcart-grocery.git
2. Open the project
cd freshcart-grocery
3. Install dependencies
npm install
4. Start the development server
npm run dev

The website will run locally at:

http://localhost:5173
